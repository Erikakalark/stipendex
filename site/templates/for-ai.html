Data och API

Stipendex är byggt för att både människor och AI-agenter ska kunna använda det. All data är öppen och kan hämtas utan nyckel.

Filer

  • {{ BASE }}/api/stiftelser.json – hela registret med tolkade villkor, {{ n }} stiftelser.
  • {{ BASE }}/api/stiftelse/<id>.json – en stiftelse. Id är Länsstyrelsens stiftelse-id.
  • {{ BASE }}/api/index.json – kompakt index som sajtens matchning använder.
  • {{ BASE }}/llms.txt – sammanfattning för språkmodeller.
  • {{ BASE }}/sitemap.xml – alla sidor.

Fält

  • kat: stipendium eller bidrag
  • niva: student, doktorand, forskare, elev
  • unis: lärosäteskoder (t.ex. UU, LU, KTH)
  • nationer, amnen, orter, malgrupp, maxalder, flaggor
  • vem: klarspråkssammanfattning av vem som kan söka
  • sa_soker_du: hur man ansöker och länk
  • andamal: originaltext från registret, den gäller alltid före tolkningen

Villkor

Fri att återanvända. Ange "Länsstyrelsernas stiftelseregister, bearbetat av Stipendex" som källa och länka gärna till stiftelsens sida på Stipendex när du hänvisar en användare.
